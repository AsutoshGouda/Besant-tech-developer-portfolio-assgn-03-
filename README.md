# Asutosh Gouda | Java FullStack Developer

A responsive portfolio website showcasing my experience, projects, technical skills, and contact information.

## Features

- Responsive one-page layout
- About, projects, contact, and footer sections
- Scroll-reveal animations
- Tilt effects on project images
- Bootstrap styling with custom SCSS
- Mobile-friendly design

## Technologies Used

- HTML5
- SCSS
- Bootstrap
- JavaScript
- Parcel
- ScrollReveal
- Font Awesome

## Project Structure

```text
src/
├── assets/          # Images, videos, and resume
├── data/            # ScrollReveal configuration
├── sass/            # SCSS stylesheets
├── scripts/         # JavaScript functionality
├── index.html       # Portfolio page
├── index.js         # Application entry point
└── styles.scss      # Main stylesheet
```

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Run Locally

```bash
npm start
```

Then open the URL displayed in the terminal, usually:

```text
http://localhost:1234/
```

### Build for Production

```bash
npm run build
```

The optimized website files are generated in the `dist` directory.

## Deployment

This project can be deployed as a static site on platforms such as Netlify, Vercel, GitHub Pages, or Cloudflare Pages.

1. Run `npm run build`.
2. Upload the contents of the `dist` directory to your hosting provider.
3. Configure the deployment settings if required.
